# LightningRoot.com

A document & image analysis tools website built with **PHP, JavaScript, HTML, Tailwind CSS, and PostgreSQL**.

## What's included

- Responsive marketing site (home and about) with header, mobile nav, footer, and a contact form built into the footer.
- **21 fully working image-analysis gauges**, computed live in the browser on canvas — no server-side image processing needed:
  1. Histogram
  2. RGB Histogram
  3. Luma Histogram
  4. Waveform Monitor
  5. RGB Parade
  6. Vectorscope
  7. False Color
  8. Zebra Pattern
  9. Clipping Detection
  10. Focus Peaking
  11. Sharpness Meter (Laplacian variance)
  12. Blur Detection
  13. Noise Meter
  14. SNR Meter
  15. Contrast Meter
  16. Dynamic Range Meter
  17. Color Distribution
  18. Cumulative Histogram
  19. FFT / Frequency Spectrum
  20. Edge Detection
  21. Gradient / Saliency Map
- An About page roadmap listing all 69 gauges and document services, grouped by category, each flagged **Live** or **Soon** — ready for you to wire up more analyses over time without redesigning the site.
- User accounts (register/login/logout) with PostgreSQL-backed sessions, and an optional "Save to my account" action on the analyze page that stores the uploaded image + its numeric gauge summary (sharpness, noise, SNR, contrast, dynamic range, clipping %) as JSON.
- **Admin panel** (`/admin`) restricted to `role = 'admin'` users: overview stats, an uploads-per-day chart, a users table, and an uploads table with quick previews and key metrics.

## Tech notes

- Frontend uses Tailwind via CDN with a custom **blue/white brand palette** (`brand-50`…`brand-950`), Inter font, and full mobile responsiveness (hamburger nav, responsive grids).
- All gauge math (histograms, Sobel edge detection, Laplacian-variance sharpness, box-blur based noise estimate, a small discrete Fourier transform for the frequency spectrum, a center-surround saliency approximation, etc.) lives in `public/assets/js/gauges.js`, fully commented, so you can extend it with the remaining 48 gauges later.
- Heavy pixel operations (Sobel, Laplacian, FFT, saliency) run on a **downscaled copy** of the image (max ~400px) for performance; simple stats like histograms and waveforms run on the full-resolution image.
- PHP is plain, framework-free, and uses PDO with prepared statements throughout.

## Setup

1. **Database**: create a PostgreSQL database and user, then load the schema:
   ```bash
   createdb lightningroot
   psql -d lightningroot -f sql/schema.sql
   ```
   Create the first administrator manually with a password hash generated by PHP's `password_hash()`. Do not store a plain-text administrator password in the schema or source code.

2. **Configuration**: put all database and mail settings in the local `.env` file. The application does not use hardcoded credential fallbacks.

   The footer contact form uses Gmail SMTP through PHPMailer. Enable 2-Step Verification on the Gmail account, create a Google App Password under **Google Account → Security → App passwords**, and configure these Apache environment variables in `C:\xampp\apache\conf\httpd.conf`:
   ```apache
   SetEnv GMAIL_SMTP_USER your-gmail-address@gmail.com
   SetEnv GMAIL_APP_PASSWORD your-16-character-app-password
   SetEnv CONTACT_EMAIL your-receiving-address@gmail.com
   ```
   Restart Apache after changing them. Never put the App Password in PHP files, JavaScript, Git, or the database. `GMAIL_SMTP_HOST` and `GMAIL_SMTP_PORT` must also be present in `.env`.

3. **Web server**: point your document root at the `public/` folder (Apache/Nginx/PHP built-in server). Example for local testing:
   ```bash
   cd public
   php -S localhost:8000
   ```
   Then visit `http://localhost:8000`.

4. **Uploads folder**: `uploads/` (outside `public/` is safer, but this build serves previews from `public/uploads` via `/admin/uploads.php` — for production, consider moving uploads outside the web root and serving them through a small PHP script that checks admin auth).

5. **Domain**: when deploying to `lightningroot.com`, point DNS at your host, set the document root to `public/`, and enable HTTPS (e.g. via Let's Encrypt).

## Structure

```
config/         DB connection + auth/session helpers
includes/       header.php, footer.php (contact form and contact bar live here)
public/         web root — all pages, /api, /admin, /assets/js
sql/schema.sql  PostgreSQL schema + default admin account
uploads/        saved images referenced by admin panel
```
